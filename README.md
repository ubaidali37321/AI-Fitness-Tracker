# AI Fitness Tracker

## About the Project
AI Fitness Tracker is a fitness management application developed using Java and Spring Boot. It helps users manage fitness-related activities through secure authentication and REST APIs.

## Features
- User authentication and authorization using Spring Security and JWT
- RESTful API development
- MySQL database integration
- Secure user access
- Fitness activity tracking

## Tech Stack
- **Language:** Java
- **Backend:** Spring Boot
- **Security:** Spring Security, JWT
- **Database:** MySQL
- **Build Tool:** Maven
- **API Testing:** Postman

## Getting Started

### Prerequisites
- Java JDK 21
- MySQL
- Maven
- IntelliJ IDEA

### Setup Instructions
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure your MySQL database.
4. Set the required environment variables.
5. Run the Spring Boot application.

### Environment Variables
Configure the database credentials using environment variables. Never commit passwords, JWT secrets, or other sensitive credentials to GitHub.

### API Testing
Use Postman to test the application's REST APIs.
